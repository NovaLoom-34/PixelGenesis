# Animal sheet concepts

`sheep-sheet-v1.png` is the concept source with 4 columns and 6 action rows. The image viewer composites semi-transparent brown edge pixels over a dark background, but alpha inspection found 24 separate opaque pose components and transparent gutters. The selected copy is `Art/Final/units/sheep_detail.png`; its metadata mask excludes the low-alpha background. Normal zoom in Unity remains to be checked.
